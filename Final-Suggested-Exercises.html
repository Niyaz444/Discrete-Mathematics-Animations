A few questions ask you to construct or reason something out — those are reveal-only, since there's no toggle for "write the negation."

1.Which of these sentences are propositions?

For each sentence: is it a statement? If it is, what's its truth value?

Why: "Boston is the capital of Massachusetts" and "2 + 3 = 5" are both declarative and checkable — both True. "x + 2 = 11" has a free variable x, so it's an open sentence, not a proposition.
2.Determine which of the following are propositions.
Why: "What time is it?" is a question — not a statement. "The moon is made of green cheese" is declarative and checkable — a proposition, and False.
3.Find the negation of the proposition:

"Abby is richer than Ricardo."

Negation: "Abby is not richer than Ricardo."

A negation only needs to flip the truth value — it doesn't need to assert the opposite extreme (like "Ricardo is richer than Abby"), since the original statement could also be False because Abby and Ricardo are equally rich.
4.What is the negation of:
2 + 1 = 3
Negation: 2 + 1 ≠ 3 — or equivalently, "It is not the case that 2 + 1 = 3." (Since the original is True, this negation is False — but it's still a perfectly valid proposition.)

"Smartphone B has the most RAM of these three smartphones."

6.Determine the truth value of the proposition:

"Nadir Software had the lowest net profit and Acme Computer had the largest annual revenue."

Why: Zenith Corp had the lowest net profit ($8M), not Nadir Software ($12M) — so the first half is False. Acme Computer did have the largest revenue ($900M) — the second half is True. Since this is a conjunction ("and"), both halves must be True for the whole thing to be True. One False half is enough to make the entire proposition False.
7.Is the assertion a proposition?

"This statement is false."

Why: No — this is the Liar Paradox. Assuming it's True forces it to be False, and assuming it's False forces it to be True. No consistent truth value exists, so it fails to be a proposition.
8.Determine whether this is a proposition:
4 + x = 5
Why: No — x is a free variable with no fixed value, so this is an open sentence. It becomes a proposition only once x is assigned a specific value (or bound by a quantifier).
9.A list of 100 statements.

The n-th statement in a list of 100 reads: "Exactly n of the statements in this list are false." What conclusions can be drawn?

Conclusion: statement 99 is True, and every other statement in the list is False.
  1. At most one statement in the list can be True. If two different statements — say the n-th and the m-th, with n ≠ m — were both True, the list would have to contain exactly n false statements and exactly m false statements at once, which is impossible.
  2. Suppose the k-th statement is the (unique) True one. Then exactly k statements are False, so exactly 100 − k are True.
  3. But we already know only one statement is True, so 100 − k = 1, giving k = 99.
  4. Check: if statement 99 is True, then exactly 99 statements are False and exactly 1 (itself) is True — perfectly consistent.
10.The barber puzzle.

In a certain town, a barber shaves every person who does not shave themselves, and only those people. Does the barber shave himself?

Neither answer works — this is a paradox.
  • If the barber does shave himself, then by the rule ("shaves only those who do not shave themselves"), he shouldn't — contradiction.
  • If the barber does not shave himself, then by the rule ("shaves everyone who does not shave themselves"), he should — contradiction.
Both options collapse into contradictions, which means no such barber can consistently exist under that rule. This is a famous illustration of self-reference breaking a system — the same structure underlies Russell's Paradox in set theory.
