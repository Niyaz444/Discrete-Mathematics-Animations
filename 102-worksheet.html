Level 1

A. Recall & Identify

1

Write the symbol for each: negation, conjunction, disjunction.

DEFNegation: ¬ (or ~). Conjunction: ∧. Disjunction: ∨.
2

In p → q, what are p and q individually called?

DEFp is the antecedent (hypothesis); q is the consequent (conclusion).
3

If a truth table has 3 statement variables, how many rows does it need?

2³ = 8Each variable doubles the combinations: 2ⁿ rows for n variables.
4

Write out the truth table for ¬p.

DEFp=T → ¬p=F. p=F → ¬p=T. Exactly one row flips to the other.
5

Under what single condition is p ↔ q True?

DEFWhen p and q have the same truth value — both True or both False.
Level 2

B. Understand & Explain

6

Explain, in your own words, why p ∧ q needs only ONE false part to become False, while p ∨ q needs BOTH parts false to become False.

💡"And" is a strict demand — everything must hold. "Or" is a generous demand — surviving on just one true part is enough. They sit at opposite ends of how much they require.
7

Explain the difference between inclusive or (∨) and exclusive or (⊕).

DEFp ∨ q is True even when both are True. p ⊕ q is True only when exactly one is True — both-True makes it False.
8

Why is p → q considered True whenever p is False, regardless of q?

💡The conditional only makes a promise about what happens if p holds. If p never holds, the promise is never broken — so it's vacuously True.
9

Explain why ¬(¬p) is the same as p.

💡Each negation flips the truth value once. Flipping twice returns to the original — the double negative cancels out.
Level 3

C. Translate & Apply

10

Let p: "The Wi-Fi is working," q: "I can submit online." Translate: "The Wi-Fi is working and I can submit online."

✓p ∧ q
11

Same p, q. Translate: "The Wi-Fi is not working, but I can still submit online."

✓¬p ∧ q
12

Given p=True, q=False, evaluate p → q.

FALSEThe only case where → is False: antecedent True, consequent False.
13

Given p=False, q=False, evaluate p ↔ q.

TRUEBoth share the same truth value (both False), so the biconditional holds.
Level 4

D. Analyze

14

Translate the "unless" sentence: "You will fail unless you study." Let p: "you study," q: "you fail." (Hint: "unless" means "if not.")

✓¬p → q — "if you don't study, then you fail."
15

A classmate translates "I will pass only if I study" as p → q where p: "I study," q: "I pass." Is this correct? Explain.

✗ INCORRECT"Only if" reverses the usual direction: "I pass only if I study" means passing requires studying, i.e. (I pass) → (I study), which is q → p here, not p → q.
16

Which connective's column reads T, T, T, F for rows TT, TF, FT, FF (in that row order)?

p ∨ qFalse only in the last row (both False) — that's disjunction's signature pattern.
Level 5

E. Create & Evaluate

17

Construct a real-life compound sentence (not about weather/umbrellas) that uses exactly one negation and one conjunction. Write both the English sentence and its symbolic form.

🧩 OPENSample: p: "The library is open," q: "I have my ID card." Sentence: "The library is not open and I have my ID card" → ¬p ∧ q. Many valid answers — check both connectives genuinely appear.
18

Critique: "Since p ∨ q and p ⊕ q both mean 'or,' they always give the same truth value." Evaluate this claim with a specific counterexample.

✗ FALSELet p=True, q=True. Then p ∨ q = True, but p ⊕ q = False (exactly one True is required). They disagree exactly when both are True.
