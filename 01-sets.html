1.1

What Is a Set?

Definition. A set is a well-defined collection of distinct objects, called its elements or members. "Well-defined" means that for any candidate object, it must be possible to say unambiguously whether it belongs to the collection or not — no vagueness, no opinion required.

We usually name sets with capital letters (A, B, C, …) and elements with lowercase letters. If a is an element of set A, we write a ∈ A ("a belongs to A" or "a is a member of A"). If it isn't, we write a ∉ A.

a ∈ A   ·   b ∉ A

Two ways to describe a set:

Roster (tabular) form — list every element inside braces: A = {2, 4, 6, 8, 10}

Set-builder form — describe a defining property: A = {x ∈ ℕ | x is even and x ≤ 10}, read "the set of all x in the natural numbers such that x is even and x is at most 10."

A set is completely determined by which elements it has — not by the order you list them in, and not by how many times you (redundantly) list an element. {1,2,3} = {3,2,1} = {1,1,2,2,3} — all three notations describe the exact same set.

1.2

Three Real-Life Examples

Sets aren't just abstract symbols — anywhere you have a well-defined collection with clear membership, you already have a set.

Enrolled Students

The set of all students officially enrolled in a Discrete Mathematics course this semester. Membership is unambiguous — the registrar's system says yes or no for any given student ID.

e.g. Roll No. 24 ∈ this set

Cryptographic Key Primes

The set of prime numbers less than 100 used to generate RSA encryption keys. Every candidate number is either prime or not — no ambiguity, which is exactly why cryptography can rely on it.

e.g. 17 ∈ this set

Server Log IP Addresses

The set of distinct IP addresses that accessed a web server in the last hour. A log file guarantees each address is counted once, regardless of how many times it actually connected.

e.g. 203.0.113.42 ∈ this set

1.5

Two Counter-Examples

"Well-defined" is doing real work in the definition. Here's what happens when it's missing.

Not a Well-Defined Set

"The collection of all tall students in this class."

Decide: is this a valid set?

Not a well-defined set. "Tall" has no fixed cutoff — one person might call 5'9" tall, another might not. Since membership depends on opinion rather than a fixed, checkable criterion, this collection fails the definition. (Fix it by replacing "tall" with an exact rule, e.g. "height ≥ 175 cm," and it becomes perfectly well-defined.)
Russell's Paradox

Let R = {x | x ∉ x} — "the set of all sets that do not contain themselves." Is R itself a member of R?

Try both answers and watch each one collapse: if R ∈ R, then by R's own defining rule, R must satisfy "x ∉ x" — so R ∉ R. Contradiction. If R ∉ R, then R satisfies its own membership rule "x ∉ x" — so R ∈ R after all. Contradiction again.

Discovered by Bertrand Russell in 1901, this broke the naive assumption that any property automatically defines a set, and pushed mathematicians toward the careful, axiomatic set theory used today.
