Problem 10

Duals of Equivalent Propositions Are Equivalent

Show that the duals of two equivalent compound propositions are also equivalent.
Why this is true

The dual of a formula is computed by swapping ∧↔∨ and T↔F everywhere. That swap is exactly the same operation, applied consistently, no matter which formula you start with. So if two formulas agree on every row (they're equivalent), performing the identical swap on both sides can't possibly make them disagree — whatever relationship held before the swap still holds after it.

Here's the idea made concrete, using the Absorption Law you already know:

Original: p∨(p∧q) ≡ p
Dual (swap ∧↔∨): p∧(p∨q) ≡ p

Problem 12

NOR Is Functionally Complete

Show that the NOR operator ↓ (where p↓q ≡ ¬(p∨q)) is a functionally complete collection of logical operators — meaning ¬, ∧, and ∨ can all be built using only ↓.
What "functionally complete" means

A set of operators is functionally complete if every possible logical connective (¬, ∧, ∨, →, ↔, …) can be constructed using only operators from that set. Since ¬, ∧, ∨ already generate everything else, it's enough to show all three can be built from ↓ alone.

¬p using only ↓
p∨q using only ↓
p∧q using only ↓
