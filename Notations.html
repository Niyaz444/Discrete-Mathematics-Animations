Socratic QuestionsThink Out Loud

1.Can a false statement still be useful?

Yes — in proof by contradiction, we deliberately assume a false statement and follow it to an absurd conclusion, which is exactly what proves the original claim true. False statements are also the backbone of counterexamples, which can instantly disprove a universal claim.

2.Why do computers dislike opinions?

A computer's logic gates and branches (if/else) need a fixed True or False to decide which path to take. An opinion has no algorithm that resolves it to True or False — feed one in, and the machine has nothing to compute with.

3.What assumption did we use?

Across today's examples, we quietly assumed every sentence is evaluated in one shared, unambiguous context — that "the door," "the Sun," or "today" refers to something both speaker and listener already agree on. Change that shared context, and a sentence's classification (or truth value) can shift.

4.Can you fool a computer with English?

Yes, easily — ambiguous pronouns, vague quantifiers ("some," "most"), and sarcasm can make a system misclassify a sentence entirely. This is exactly why mathematics abandons English for symbols: symbols don't carry hidden ambiguity.

5.Can a sentence become a statement later?

Why: Yes — an open sentence like x + 5 = 9 isn't a statement yet, but the moment its free variable is fixed to a specific value (or bound by a quantifier), it becomes a genuine statement with a definite truth value.

6.Can one counterexample destroy a universal claim?

Why: Yes — a claim like "all prime numbers are odd" only needs one exception (2 is prime and even) to be proven False. Universal claims are fragile that way: a thousand confirming cases prove nothing, but a single counterexample settles it.

7.Can two students disagree about a statement's truth value?

They can disagree about what they believe is true — due to a mistake, missing information, or a misread question — but the statement itself still has exactly one objective truth value. Their disagreement is about knowledge, not about the statement secretly having two truth values.

8.Why does mathematics replace English by symbols?

Symbols remove ambiguity, let us manipulate claims using fixed rules (like algebra manipulates numbers), and make the same reasoning apply no matter what the statements are actually about.

9.Can you invent a sentence that nobody in this room can classify?

Try building a genuine self-referential paradox, different from "This statement is false" — e.g. pairing two sentences that each refer to the other. If it forces truth to flip endlessly with no stable resolution, you've built something even the whole room can't classify.

10.What do you think we shall study next to handle x > 5?

Why: x > 5 is exactly an open sentence — a predicate P(x) — that only becomes a statement once x is fixed or bound by a quantifier ("for all x," "there exists x"). That's precisely what Predicates and Quantifiers, later in this module, will formalise.

Conceptual Question

Why is "Truth" alone insufficient for mathematics? Why do we require statements?

"Truth" alone doesn't tell you whether a sentence was even eligible to be checked in the first place. Mathematics needs sentences that are both declarative and objectively decidable — that's the statement requirement. Without it, "true-feeling" opinions could sneak into proofs with no shared way to verify them.
Prediction Question

Suppose computers could understand emotions. Would mathematical logic still require statements? Explain.

Yes — mathematical logic isn't built around what a computer can process, it's built around what makes an argument valid. Even an emotionally intelligent computer would still need a fixed, checkable truth value to chain deductions together; understanding feelings doesn't change what counts as a valid proof step.

Proof Detective

A student claims x² = 25 is a statement because "it is true when x = 5." Find the mistake.

Why: The formal definition requires a fixed truth value for the sentence as written. "It is true when x = 5" describes one instance, not the sentence itself — the sentence x² = 25 stays an open sentence until x is pinned down (or quantified) for good, not just tested at a single convenient value.

Challenge QuestionTrue, False, or Neither?

Consider the following sentence.

x² − 5x + 6 = 0

"It is TRUE."  ·  "It is FALSE."  ·  "It is neither." Which is correct?

Why: "Neither" — x is a free variable, so this is an open sentence, not a statement, and open sentences have no truth value to assign at all.

Can it ever become a statement? Yes — if x is fixed to a specific number (e.g. "when x = 2"), or bound by a quantifier ("for some x," "for all x"), it becomes a genuine statement with a definite truth value.
Abstract ThinkingDiscuss With Your Partner First

Suppose P: "2 is an odd number." Since P is false, can we still use it in mathematical proofs?

Why: Yes — logic treats True and False completely symmetrically as valid inputs. A false P is essential for techniques like proof by contradiction (assume something false-implying and derive an absurdity) and for building counterexamples.

Would mathematics become impossible if false statements were forbidden? Largely, yes — entire proof techniques (contradiction, disproof by counterexample) depend on being able to state and reason about false claims. Banning False would cripple half of mathematical reasoning.
Pause – Review – ProceedBefore Logical Connectives

Before proceeding to logical connectives, verify that you can answer all the following. If you hesitate on any answer, pause here, discuss with your classmates, and convince each other mathematically. Only then proceed.

1.What is a statement variable?

A lowercase letter (like p, q, r, or sometimes an uppercase P, Q) used to stand in for a whole statement, so it can be manipulated symbolically.

2.Why do mathematicians prefer symbols instead of English sentences?

Symbols are unambiguous and let the same manipulation rules apply regardless of what the statement is actually about — English carries hidden ambiguity that symbols strip away.

3.Can a statement variable represent an algebraic expression?

No — not on its own. An algebraic expression like x + 5 has no truth value; only a full declarative sentence with a definite truth value (like "x + 5 = 9" once x is fixed) can be represented by a statement variable.

4.Can two different statements both be represented by the symbol P within the same discussion?

Not without causing confusion — within a single discussion, each symbol should represent exactly one fixed statement. Reusing P for two different statements breaks the whole point of notation: keeping meaning unambiguous.

5.Why does a computer manipulate symbols instead of meanings?

A computer has no access to "meaning" the way a person does — it can only follow fixed rules on fixed symbols. This is actually why formal logic works so well for computers: correct symbol manipulation guarantees correct conclusions, without the machine ever needing to "understand" anything.
