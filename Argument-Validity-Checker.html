Reference — what makes an argument valid

  • An argument is Valid if, in every row where all premises are True, the conclusion is also True.
  • An argument is Invalid if there is even one row where every premise is True but the conclusion is False.
  • This connects directly back to tautologies: an argument is valid exactly when (P1 ∧ P2 ∧ … ) → C is a tautology.
