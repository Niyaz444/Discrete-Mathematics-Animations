Topic 3 — Tautologies, Logic

Always, Never, Sometimes

10 quick-fire questions. Today we ask: can a compound statement be True no matter what its parts do?

5 min
1Lv1

Recap: what symbol means "not," and what does it do to a truth value?

¬Negation. It flips the truth value: True becomes False, False becomes True.
2Lv2

Guess: is "p or not-p" (e.g. "It is raining, or it is not raining") ever False, for any weather?

✓ NEVER FALSEOne of the two sides is always true — rain or no rain, exactly one holds, so the "or" always succeeds.
3Lv2

Guess: can "p and not-p" (e.g. "It is raining, and it is not raining") ever be True at the same time?

✗ NEVER TRUEA claim and its exact opposite can't both hold. This combination is always False.
4Lv1

True or False: a statement like p ∧ q can be True for some values of p, q and False for others.

✓ TRUEIt depends entirely on the inputs — this kind of "it depends" statement is exactly what we'll name today.
5Lv3

If you built a full truth table for a statement and every single row came out True, what would you want to call that statement?

🔮 PREVIEWA tautology — always true, no matter the input. Hold that guess!
6Lv3

And the opposite — every row False. What would you call that?

🔮 PREVIEWA contradiction (sometimes called a fallacy) — always false, no matter the input.
7Lv4

Why might it be useful in mathematics to have statements that are always true, regardless of the situation?

💡 IDEAYou can drop them into any proof, anywhere, without checking conditions first — they're guaranteed building blocks that never need justification beyond "this is always true."
8Lv2

Consider p → p ("if p then p"). Guess: is this always True, always False, or does it depend?

ALWAYS TRUEAnything implies itself. There's no way for the antecedent to be true and the consequent false when they're identical.
9Lv4

Why is it logically impossible for p and ¬p to both hold at once?

💡 IDEABy definition, ¬p is true exactly when p is false. They're built to always disagree — asking for both is a built-in contradiction.
10Lv5

One-line guess: how might a "tautology" be useful as a tool inside a longer mathematical proof?

🔮 PREVIEWTautologies act as trusted stepping stones — since they're guaranteed true, a proof can lean on one at any point without extra justification. We'll see this power grow next topic.
