Power Set

The set of every possible subset — including the ones you'd never think to count. A set whose elements are themselves sets.

Topic 5 of 6 · Set Theory Series
5.1

What Is a Power Set?

Definition. The power set of A, written 𝒫(A) or 2^A, is the set of every subset of A — 𝒫(A) = {S | S ⊆ A}. That includes ∅ and A itself.

Crucial subtlety: 𝒫(A) is a set of sets. Every single element of 𝒫(A) is itself a set (possibly the empty one). This trips people up constantly — keep reading for exactly how.

|𝒫(A)| = 2^|A|
∅ ∈ 𝒫(A)

Always true, for any A — since ∅ ⊆ A always holds.

A ∈ 𝒫(A)

Always true — since A ⊆ A always holds (reflexivity).

x∈A ⟹ {x}∈𝒫(A)

An element of A becomes a singleton subset in 𝒫(A) — not the same object.

|A|=n ⟹ |𝒫(A)|=2ⁿ

Every element independently is "in" or "out" of a candidate subset — 2 choices, n times.

5.2

Three Real-Life Examples

Every time you're choosing "any combination of," you're really navigating a power set.

Pizza Toppings

With toppings {pepperoni, mushroom, olive}, every possible order — from plain cheese to all three — is one element of the power set of the topping set.

2³ = 8 possible orders

Phone Settings

Four toggles — Wi-Fi, Bluetooth, GPS, Airplane Mode — each independently on or off. Every possible configuration is exactly one element of the power set.

2⁴ = 16 configurations

Committee Formation

From a 5-person team, any sub-committee you could possibly form — including the empty committee and the full team — is an element of the power set of the team.

2⁵ = 32 possible committees

5.5

Two Counter-Examples

Power sets have two classic traps — both waiting right at the definition.

False Claim

"The power set of the empty set is empty: 𝒫(∅) = ∅."

False — this is the single most famous power-set surprise. 𝒫(∅) = {∅}. It's a set containing one element — the empty set itself — so |𝒫(∅)| = 2⁰ = 1, not 0. ∅ and {∅} are completely different objects: ∅ has zero elements; {∅} has exactly one element (which happens to be ∅). Confusing "empty" with "a box containing nothing" is exactly this mistake.
False Claim

"If 1 ∈ A, then 1 ∈ 𝒫(A) too."

False — this is the ∈ vs ⊆ trap, one level up. With A = {1,2}: the elements of 𝒫(A) are ∅, {1}, {2}, {1,2} — every one of them is a set. The number 1 by itself is not a set, so 1 ∉ 𝒫(A). What's actually true is {1} ∈ 𝒫(A) — wrap the element in braces first, since 𝒫(A) only ever contains sets.
